# Local-Foodie
This is our capstone project.

The Local Foodie helps you find locally owned restaurants and cafés near you, using AI-powered search and no chains, so every meal supports your community. 

This website is currently deployed to https://local-foodie-site.onrender.com/

To run this application locally:

1. Run "npm install" in console
2. Run "npm run dev" 
3. Run "npm run server" 
4. Go to http://localhost:5173/ on your browser
